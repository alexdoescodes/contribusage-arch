# L-3: GitHub Contributions Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Show GitHub contributions in the widget. The user pastes a GitHub token into the GitHub block. The widget validates it, keeps it in KWallet, and every 30 minutes fetches the last year of contributions. It then shows today, the streak and the year, and draws GitHub's green layer in the heatmap.

**Architecture:**
- **Two seams in the core** (abstract, Qt6::Core only): `HttpTransport` and `SecretStore`, both asynchronous with a context guard, like L-1a's process runner.
- **`contribusage_github`** (`src/github/`, links only the core) holds the GitHub logic: report types and statistics, the GraphQL client, the account (token rules), a job with interval, cache and states, and the view for QML.
- **`contribusage_platform`** (`src/platform/`) holds the live implementations: `NetworkTransport` (QNetworkAccessManager) and `KWalletSecretStore` (KF6 Wallet). It is the only library that links Qt6::Network and KF6::Wallet.
- **The applet** (`PopupModel`) wires them up, and the GitHub block gets an inline token form.

**Tech Stack:** C++23, Qt 6 Core and Network, KF6 Wallet, QML, Qt Test (plus a local `QTcpServer` for the transport test).

**Spec:**
- **Requirements:** SPEC §8.4 (request, token, rate limits, statistics), FR-16 to FR-20, §11.3 (GitHub states), §12 (GitHub interval 30 min), §13, §14 (a token is saved only after GitHub accepted it).
- **Decisions:** ADR-020 (rate limit detection), ADR-021 (week start), ADR-022 (GitHub job rules: 401 pauses until the token changes).
- **Port design:** §1 (seams table: the secret store uses KWallet over the Secret Service API).
- **Swift reference** (read with `git show 2603a21:<path>`): `Packages/ContribusageKit/Sources/ContribusageGitHub/{GitHubClient,GitHubReport,GitHubAccount}.swift`, and the tests and fixtures in `Packages/ContribusageKit/Tests/ContribusageGitHubTests/`.

## Global Constraints

- Everything from the earlier plans still holds: C++23, `-Werror`, clang-format clean (**only on `*.cpp` and `*.h`, never on a glob that catches `CMakeLists.txt`**), `QStringLiteral`, no exceptions, and `src/core/` links only Qt6::Core.
- **Hard rules (SPEC §2, AGENTS.md):**
  - The only network destination is `https://api.github.com/graphql`.
  - The GitHub token goes only into KWallet (folder `contribusage`, key `token`) and never into logs, files, `state.json` or QML properties after it is submitted.
  - No other tool's credentials are read: no `gh auth token` here; FR-21 is P3 and later.
- A token is saved only after `viewer { login }` succeeds with it (SPEC §14). A rejected token never replaces a saved one.
- GitHub interval 30 min (SPEC §12). A 401 pauses fetching until the token changes (ADR-022). A rate limit waits until `x-ratelimit-reset` (ADR-020).
- Statistics: today is the local date; the week starts on the locale's first day of the week (`QLocale().firstDayOfWeek()`, ADR-021).
- Tests never touch the network or the real wallet: they use `FakeHttpTransport`, `FakeSecretStore` and a local `QTcpServer`. The live KWallet store is checked by hand.

## Review Focus

1. **A wrong, expired or revoked token.** Expected: connect shows "GitHub token is invalid or expired" and keeps any saved token; a 401 during refresh stops polling until a new token is connected. Pinned in Task 3 (`connectKeepsARejectedTokenOut`) and Task 5 (`unauthorizedPausesUntilTheTokenChanges`).
2. **No network.** Expected: "Offline" with the previous numbers dimmed, never a crash or a freeze. Pinned in Task 4 (`unreachableHostIsOffline`) and Task 5 (`failureKeepsThePreviousSnapshot`).
3. **Rate limited.** Expected: "Rate limited until HH:mm", and no requests before that time. Pinned in Task 2 (`sendMapsFailures`) and Task 5 (`rateLimitWaitsForTheReset`).
4. **The token stays secret.** Expected: it is never written anywhere but the secret store, and the QML field is cleared after submit. Pinned in Task 5 (`cacheHoldsNoToken`) and Task 6 (`githubFormClearsTheToken`).
5. **GitHub adds a contribution level.** Expected: a loud decoding error rather than wrong colors. Pinned in Task 2 (`contributionsRejectsAnUnknownLevel`).

```cpp
#pragma once

#include <QDate>

namespace contribusage::github {

// SPEC §10.5: one day of GitHub's calendar; `level` is GitHub's contributionLevel, 0 (none) to 4 (fourth quartile).
struct ContributionDay {
    QDate date;
    int count = 0;
    int level = 0;

    bool operator==(const ContributionDay &) const = default;
};

// FR-18: the calendar as GitHub returns it; its weeks start on Sunday, the first and the last one can be short.
struct ContributionCalendar {
    QString login;
    QList<QList<ContributionDay>> weeks;
    int totalContributions = 0;

    QList<ContributionDay> days() const;
    bool operator==(const ContributionCalendar &) const = default;
};

struct ContributionStats {
    int today = 0;
    int thisWeek = 0;
    int currentStreak = 0;
    bool streakNeedsToday = false; // today is 0 so far; the streak is counted up to yesterday
    int longestStreak = 0;

    bool operator==(const ContributionStats &) const = default;
};

// FR-19, SPEC §8.4.4 over consecutive `days` in API order. Days after `today` (GitHub's day ahead of the local one)
// count nowhere; the week starts on `firstDayOfWeek` (ADR-021).
ContributionStats contributionStats(const QList<ContributionDay> &days, QDate today, Qt::DayOfWeek firstDayOfWeek);

struct GitHubReport {
    ContributionCalendar calendar;
    ContributionStats stats;

    bool operator==(const GitHubReport &) const = default;
};

// The JSON form in state.json (SPEC §10.7); nullopt for a missing or wrongly typed field.
QJsonObject toJson(const GitHubReport &report);
std::optional<GitHubReport> gitHubReportFromJson(const QJsonObject &json);

} // namespace contribusage::github
```

`src/github/githubreport.cpp`:
```cpp
#include "github/githubreport.h"

#include <QJsonArray>

#include <algorithm>

namespace contribusage::github {

QList<ContributionDay> ContributionCalendar::days() const {
    QList<ContributionDay> all;
    for (const auto &week : weeks) {
        all.append(week);
    }
    return all;
}

ContributionStats contributionStats(const QList<ContributionDay> &days, QDate today, Qt::DayOfWeek firstDayOfWeek) {
    QList<ContributionDay> past;
    for (const ContributionDay &day : days) {
        if (day.date <= today) {
            past.append(day);
        }
    }
    ContributionStats stats;
    for (auto it = past.crbegin(); it != past.crend(); ++it) {
        if (it->date == today) {
            stats.today = it->count;
            break;
        }
    }
    const QDate weekStart = today.addDays(-((today.dayOfWeek() - int(firstDayOfWeek) + 7) % 7));
    for (const ContributionDay &day : past) {
        if (day.date >= weekStart) {
            stats.thisWeek += day.count;
        }
    }
    // Today at 0 so far (or not in the calendar yet) leaves the streak ending yesterday.
    auto it = past.crbegin();
    if (it != past.crend() && it->date == today && it->count == 0) {
        ++it;
    }
    for (; it != past.crend() && it->count > 0; ++it) {
        ++stats.currentStreak;
    }
    stats.streakNeedsToday = stats.today == 0 && stats.currentStreak > 0;
    int run = 0;
    for (const ContributionDay &day : past) {
        run = day.count > 0 ? run + 1 : 0;
        stats.longestStreak = std::max(stats.longestStreak, run);
    }
    return stats;
}

QJsonObject toJson(const GitHubReport &report) {
    QJsonArray weeks;
    for (const auto &week : report.calendar.weeks) {
        QJsonArray days;
        for (const ContributionDay &day : week) {
            days.append(QJsonObject{{QStringLiteral("date"), day.date.toString(Qt::ISODate)},
                                    {QStringLiteral("count"), day.count},
                                    {QStringLiteral("level"), day.level}});
        }
        weeks.append(days);
    }
    const ContributionStats &stats = report.stats;
    return {{QStringLiteral("calendar"),
             QJsonObject{{QStringLiteral("login"), report.calendar.login},
                         {QStringLiteral("weeks"), weeks},
                         {QStringLiteral("totalContributions"), report.calendar.totalContributions}}},
            {QStringLiteral("stats"), QJsonObject{{QStringLiteral("today"), stats.today},
                                                  {QStringLiteral("thisWeek"), stats.thisWeek},
                                                  {QStringLiteral("currentStreak"), stats.currentStreak},
                                                  {QStringLiteral("streakNeedsToday"), stats.streakNeedsToday},
                                                  {QStringLiteral("longestStreak"), stats.longestStreak}}}};
}

std::optional<GitHubReport> gitHubReportFromJson(const QJsonObject &json) {
    const QJsonObject calendar = json.value(QStringLiteral("calendar")).toObject();
    const QJsonObject stats = json.value(QStringLiteral("stats")).toObject();
    if (!calendar.value(QStringLiteral("login")).isString() || !calendar.value(QStringLiteral("weeks")).isArray() ||
        !calendar.value(QStringLiteral("totalContributions")).isDouble()) {
        return std::nullopt;
    }
    for (const auto *key : {"today", "thisWeek", "currentStreak", "longestStreak"}) {
        if (!stats.value(QLatin1StringView(key)).isDouble()) {
            return std::nullopt;
        }
    }
    if (!stats.value(QStringLiteral("streakNeedsToday")).isBool()) {
        return std::nullopt;
    }
    GitHubReport report{
        .calendar = {.login = calendar.value(QStringLiteral("login")).toString(),
                     .weeks = {},
                     .totalContributions = calendar.value(QStringLiteral("totalContributions")).toInt()},
        .stats = {.today = stats.value(QStringLiteral("today")).toInt(),
                  .thisWeek = stats.value(QStringLiteral("thisWeek")).toInt(),
                  .currentStreak = stats.value(QStringLiteral("currentStreak")).toInt(),
                  .streakNeedsToday = stats.value(QStringLiteral("streakNeedsToday")).toBool(),
                  .longestStreak = stats.value(QStringLiteral("longestStreak")).toInt()}};
    for (const QJsonValue &weekValue : calendar.value(QStringLiteral("weeks")).toArray()) {
        if (!weekValue.isArray()) {
            return std::nullopt;
        }
        QList<ContributionDay> week;
        for (const QJsonValue &dayValue : weekValue.toArray()) {
            const QJsonObject day = dayValue.toObject();
            const QDate date = QDate::fromString(day.value(QStringLiteral("date")).toString(), Qt::ISODate);
            if (!date.isValid() || !day.value(QStringLiteral("count")).isDouble() ||
                !day.value(QStringLiteral("level")).isDouble()) {
                return std::nullopt;
            }
            week.append({.date = date,
                         .count = day.value(QStringLiteral("count")).toInt(),
                         .level = day.value(QStringLiteral("level")).toInt()});
        }
        report.calendar.weeks.append(week);
    }
    return report;
}

} // namespace contribusage::github
```

```cpp
#pragma once

#include "core/reports.h"

#include <QByteArray>
#include <QList>
#include <QMap>
#include <QObject>
#include <QString>
#include <QUrl>

#include <expected>
#include <functional>
#include <optional>
#include <utility>

namespace contribusage {

// SPEC §10.6. Like ProcessRunning, every call is asynchronous, answers once on the GUI thread, and drops its answer
// when `context` was destroyed first. Live implementations live in src/platform/; fakes in tests/support/.

struct HttpRequest {
    QUrl url;
    QList<std::pair<QByteArray, QByteArray>> headers;
    QByteArray body;
};

struct HttpResponse {
    int status = 0;
    QMap<QByteArray, QByteArray> headers; // names in lower case
    QByteArray body;
};

using HttpOutcome = std::expected<HttpResponse, SourceError>;

// A POST; a response with any HTTP status is an outcome, a transport failure is `Offline` (or `TimedOut`).
class HttpTransport {
public:
    virtual ~HttpTransport() = default;
    virtual void post(const HttpRequest &request, QObject *context, std::function<void(HttpOutcome)> done) = 0;
};

using SecretRead = std::expected<std::optional<QString>, SourceError>;
using SecretWrite = std::expected<void, SourceError>;

// Holds only the widget's own secrets (the GitHub token, FR-16), never another tool's (SPEC §2). Removing a missing
// key succeeds.
class SecretStore {
public:
    virtual ~SecretStore() = default;
    virtual void read(const QString &key, QObject *context, std::function<void(SecretRead)> done) = 0;
    virtual void write(const QString &key, const QString &value, QObject *context,
                       std::function<void(SecretWrite)> done) = 0;
    virtual void remove(const QString &key, QObject *context, std::function<void(SecretWrite)> done) = 0;
};

} // namespace contribusage
```

```cpp
#pragma once

#include "core/seams.h"

#include <QPointer>
#include <QTimer>

// Answers every POST with the configured response (or `failure`), on the next event loop pass, and records requests.
class FakeHttpTransport final : public contribusage::HttpTransport {
public:
    void respond(int status, const QByteArray &body, const QMap<QByteArray, QByteArray> &headers = {}) {
        response = {.status = status, .headers = headers, .body = body};
        failure.reset();
    }

    void post(const contribusage::HttpRequest &request, QObject *context,
              std::function<void(contribusage::HttpOutcome)> done) override {
        requests.append(request);
        const contribusage::HttpOutcome outcome =
            failure ? contribusage::HttpOutcome(std::unexpected(*failure)) : contribusage::HttpOutcome(response);
        const QPointer<QObject> guard = context;
        const bool hasContext = context != nullptr;
        QTimer::singleShot(0, [guard, hasContext, outcome, done = std::move(done)]() {
            if (!hasContext || guard) {
                done(outcome);
            }
        });
    }

    contribusage::HttpResponse response{.status = 500, .headers = {}, .body = {}};
    std::optional<contribusage::SourceError> failure;
    QList<contribusage::HttpRequest> requests;
};
```

```cpp
// An in-memory SecretStore; answers on the next event loop pass, like the wallet.
class FakeSecretStore final : public contribusage::SecretStore {
public:
    void read(const QString &key, QObject *context, std::function<void(contribusage::SecretRead)> done) override {
        const contribusage::SecretRead outcome =
            values.contains(key) ? std::optional<QString>(values.value(key)) : std::optional<QString>();
        later(context, [outcome, done = std::move(done)] { done(outcome); });
    }
    void write(const QString &key, const QString &value, QObject *context,
               std::function<void(contribusage::SecretWrite)> done) override {
        values.insert(key, value);
        later(context, [done = std::move(done)] { done({}); });
    }
    void remove(const QString &key, QObject *context, std::function<void(contribusage::SecretWrite)> done) override {
        values.remove(key);
        later(context, [done = std::move(done)] { done({}); });
    }

    QMap<QString, QString> values;

private:
    static void later(QObject *context, std::function<void()> action) {
        const QPointer<QObject> guard = context;
        const bool hasContext = context != nullptr;
        QTimer::singleShot(0, [guard, hasContext, action = std::move(action)]() {
            if (!hasContext || guard) {
                action();
            }
        });
    }
```

```cpp
void GitHubClient::viewerLogin(const QString &token, QObject *context,
                               std::function<void(std::expected<QString, SourceError>)> done) {

void GitHubClient::contributions(const QString &token, const QDateTime &from, const QDateTime &to, QObject *context,
                                 std::function<void(std::expected<ContributionCalendar, SourceError>)> done) {
    const QJsonObject variables{{QStringLiteral("from"), from.toString(Qt::ISODate)},
                                {QStringLiteral("to"), to.toString(Qt::ISODate)}};
    send(QString::fromLatin1(contributionsQuery), variables, token, context,
         [done = std::move(done)](std::expected<QJsonObject, SourceError> data) {
             if (!data) {
                 done(std::unexpected(data.error()));
                 return;
             }
             const QJsonObject viewer = data->value(QStringLiteral("viewer")).toObject();
             const QJsonObject calendar = viewer.value(QStringLiteral("contributionsCollection"))
                                              .toObject()
                                              .value(QStringLiteral("contributionCalendar"))
                                              .toObject();
             if (!viewer.value(QStringLiteral("login")).isString() || !calendar.value(QStringLiteral("weeks")).isArray()) {
                 done(std::unexpected(decoding(QStringLiteral("No calendar in response"))));
                 return;
             }
             ContributionCalendar result{.login = viewer.value(QStringLiteral("login")).toString(),
                                         .weeks = {},
                                         .totalContributions = calendar.value(QStringLiteral("totalContributions")).toInt()};
             for (const QJsonValue &weekValue : calendar.value(QStringLiteral("weeks")).toArray()) {
                 QList<ContributionDay> week;
                 for (const QJsonValue &dayValue :
                      weekValue.toObject().value(QStringLiteral("contributionDays")).toArray()) {
                     const QJsonObject day = dayValue.toObject();
                     const QString levelName = day.value(QStringLiteral("contributionLevel")).toString();
                     const qsizetype level = levelNames.indexOf(levelName);
                     if (level < 0) {
                         done(std::unexpected(decoding(QStringLiteral("Unknown contribution level ") + levelName)));
                         return;
                     }
                     week.append({.date = QDate::fromString(day.value(QStringLiteral("date")).toString(), Qt::ISODate),
                                  .count = day.value(QStringLiteral("contributionCount")).toInt(),
                                  .level = int(level)});
                 }
                 result.weeks.append(week);
             }
             done(result);
         });
}

void GitHubClient::send(const QString &query, const QJsonObject &variables, const QString &token, QObject *context,
                        std::function<void(std::expected<QJsonObject, SourceError>)> done) {
    const HttpRequest request{
        .url = graphqlEndpoint(),
        .headers = {{"Authorization", QByteArray("Bearer ") + token.toUtf8()},
                    {"User-Agent", m_userAgent},
                    {"Content-Type", "application/json"}},
        .body = QJsonDocument(QJsonObject{{QStringLiteral("query"), query}, {QStringLiteral("variables"), variables}})
                    .toJson(QJsonDocument::Compact)};
    m_transport.post(request, context, [done = std::move(done)](HttpOutcome outcome) {
        if (!outcome) {
            done(std::unexpected(outcome.error()));
            return;
        }
        const HttpResponse &response = *outcome;
        if (response.status == 401) {
            done(std::unexpected(SourceError{.kind = SourceError::Kind::Unauthorized}));
            return;
        }
        SourceError failure;
        if (response.status >= 200 && response.status < 300) {
            QJsonParseError parseError;
            const QJsonObject envelope = QJsonDocument::fromJson(response.body, &parseError).object();
            if (parseError.error != QJsonParseError::NoError) {
                done(std::unexpected(decoding(parseError.errorString())));
                return;
            }
            const QJsonArray errors = envelope.value(QStringLiteral("errors")).toArray();
            if (envelope.value(QStringLiteral("data")).isObject() && errors.isEmpty()) {
                done(envelope.value(QStringLiteral("data")).toObject());
                return;
            }
            failure = decoding(errors.isEmpty()
                                   ? QStringLiteral("No data in response")
                                   : errors.first().toObject().value(QStringLiteral("message")).toString());
        } else {
            failure = {.kind = SourceError::Kind::Http, .code = response.status};
        }
        // ADR-020: any failure with an exhausted budget (200 with errors, 403, 429) waits for the reset.
        bool resetOk = false;
        const qint64 reset = response.headers.value("x-ratelimit-reset").toLongLong(&resetOk);
        if (response.headers.value("x-ratelimit-remaining") == "0" && resetOk) {
            done(std::unexpected(
                SourceError{.kind = SourceError::Kind::RateLimited, .until = QDateTime::fromSecsSinceEpoch(reset)}));
            return;
        }
        done(std::unexpected(failure));
    });
}
```

```cpp
void GitHubAccount::connect(const QString &token, QObject *context,
                            std::function<void(std::expected<QString, SourceError>)> done) {
    m_client.viewerLogin(token, context, [this, token, context, done = std::move(done)](auto login) mutable {
        if (!login) {
            done(std::unexpected(login.error()));
            return;
        }
        m_secrets.write(tokenKey, token, context, [login = *login, done = std::move(done)](SecretWrite written) {
            if (!written) {
                done(std::unexpected(written.error()));
                return;
            }
            done(login);
        });
    });
}

void GitHubAccount::report(const QDateTime &now, Qt::DayOfWeek firstDayOfWeek, QObject *context,
                           std::function<void(std::expected<GitHubReport, SourceError>)> done) {
    m_secrets.read(tokenKey, context, [this, now, firstDayOfWeek, context, done = std::move(done)](SecretRead token) mutable {
        if (!token) {
            done(std::unexpected(token.error()));
            return;
        }
        if (!token->has_value()) {
            done(std::unexpected(SourceError{.kind = SourceError::Kind::TokenMissing}));
            return;
        }
        const QDateTime from(now.date().addDays(-364), QTime(0, 0), now.timeZone());
        m_client.contributions(**token, from, now, context,
                               [now, firstDayOfWeek, done = std::move(done)](auto calendar) {
                                   if (!calendar) {
                                       done(std::unexpected(calendar.error()));
                                       return;
                                   }
                                   done(GitHubReport{.calendar = *calendar,
                                                     .stats = contributionStats(calendar->days(), now.date(),
                                                                                firstDayOfWeek)});
                               });
    });
}

void GitHubAccount::disconnect(QObject *context, std::function<void(SecretWrite)> done) {
    m_secrets.remove(tokenKey, context, std::move(done));
}
```

```cpp
#include <QNetworkReply>
#include <QNetworkRequest>
#include <QPointer>

namespace contribusage {

void NetworkTransport::post(const HttpRequest &request, QObject *context, std::function<void(HttpOutcome)> done) {
    QNetworkRequest networkRequest(request.url);
    for (const auto &[name, value] : request.headers) {
        networkRequest.setRawHeader(name, value);
    }
    networkRequest.setTransferTimeout(30'000);
    QNetworkReply *reply = m_manager.post(networkRequest, request.body);
    const QPointer<QObject> guard = context;
    const bool hasContext = context != nullptr;
    QObject::connect(reply, &QNetworkReply::finished, reply, [reply, guard, hasContext, done = std::move(done)] {
        reply->deleteLater();
        if (hasContext && !guard) {
            return;
        }
        const QVariant status = reply->attribute(QNetworkRequest::HttpStatusCodeAttribute);
        if (!status.isValid()) {
            // No HTTP answer: DNS, connection or timeout failures.
            done(std::unexpected(SourceError{.kind = reply->error() == QNetworkReply::OperationCanceledError ||
                                                             reply->error() == QNetworkReply::TimeoutError
                                                         ? SourceError::Kind::TimedOut
                                                         : SourceError::Kind::Offline,
                                             .text = reply->errorString()}));
            return;
        }
        HttpResponse response{.status = status.toInt(), .headers = {}, .body = reply->readAll()};
        for (const auto &[name, value] : reply->rawHeaderPairs()) {
            response.headers.insert(name.toLower(), value);
        }
        done(response);
    });
}
```

```cpp
#include <KWallet>

namespace contribusage {

namespace {
const QString folder = QStringLiteral("contribusage");

SourceError unavailable() {
    return {.kind = SourceError::Kind::Io, .text = QStringLiteral("KWallet is not available")};
}
} // namespace

KWalletSecretStore::KWalletSecretStore(QObject *parent) : QObject(parent) {}

KWalletSecretStore::~KWalletSecretStore() = default;

void KWalletSecretStore::withWallet(QObject *context, std::function<void(KWallet::Wallet *)> action) {
    if (m_wallet && m_wallet->isOpen()) {
        action(m_wallet.get());
        return;
    }
    m_waiting.append({.context = context, .hasContext = context != nullptr, .action = std::move(action)});
    if (m_opening) {
        return;
    }
    m_opening = true;
    m_wallet.reset(KWallet::Wallet::openWallet(KWallet::Wallet::NetworkWallet(), 0, KWallet::Wallet::Asynchronous));
    if (!m_wallet) {
        flush(false);
        return;
    }
    connect(m_wallet.get(), &KWallet::Wallet::walletOpened, this, [this](bool opened) { flush(opened); });
}

void KWalletSecretStore::flush(bool opened) {
    m_opening = false;
    KWallet::Wallet *wallet = nullptr;
    if (opened && m_wallet) {
        if (!m_wallet->hasFolder(folder)) {
            m_wallet->createFolder(folder);
        }
        if (m_wallet->setFolder(folder)) {
            wallet = m_wallet.get();
        }
    }
    const QList<Waiting> waiting = std::exchange(m_waiting, {});
    for (const Waiting &entry : waiting) {
        if (!entry.hasContext || entry.context) {
            entry.action(wallet);
        }
    }
    if (!wallet && m_wallet) {
        m_wallet.release()->deleteLater(); // try again on the next request
    }
}

void KWalletSecretStore::read(const QString &key, QObject *context, std::function<void(SecretRead)> done) {
    withWallet(context, [key, done = std::move(done)](KWallet::Wallet *wallet) {
        if (!wallet) {
            done(std::unexpected(unavailable()));
            return;
        }
        if (!wallet->hasEntry(key)) {
            done(std::optional<QString>());
            return;
        }
        QString value;
        if (wallet->readPassword(key, value) != 0) {
            done(std::unexpected(unavailable()));
            return;
        }
        done(std::optional<QString>(value));
    });
}

void KWalletSecretStore::write(const QString &key, const QString &value, QObject *context,
                               std::function<void(SecretWrite)> done) {
    withWallet(context, [key, value, done = std::move(done)](KWallet::Wallet *wallet) {
        if (!wallet || wallet->writePassword(key, value) != 0) {
            done(std::unexpected(unavailable()));
            return;
        }
        done({});
    });
}

void KWalletSecretStore::remove(const QString &key, QObject *context, std::function<void(SecretWrite)> done) {
    withWallet(context, [key, done = std::move(done)](KWallet::Wallet *wallet) {
        if (!wallet) {
            done(std::unexpected(unavailable()));
            return;
        }
        if (wallet->hasEntry(key) && wallet->removeEntry(key) != 0) {
            done(std::unexpected(unavailable()));
            return;
        }
        done({});
    });
}
```

```cpp
#include "github/githubjob.h"

#include "core/jsonstore.h"
#include "core/limitscache.h"

#include <QJsonObject>
#include <QLocale>

namespace contribusage::github {

namespace githubcache {

namespace {
QString file(const AppPaths &paths) {
    return paths.root + QStringLiteral("/state.json");
}

QJsonObject state(const AppPaths &paths) {
    const auto read = jsonstore::read(file(paths), limitscache::schemaVersion);
    return read && read->has_value() ? read->value().toObject() : QJsonObject();
}
} // namespace

std::optional<Snapshot<GitHubReport>> load(const AppPaths &paths) {
    const QJsonObject entry = state(paths).value(QStringLiteral("github")).toObject();
    const QDateTime fetchedAt =
        QDateTime::fromString(entry.value(QStringLiteral("fetchedAt")).toString(), Qt::ISODateWithMs);
    const auto report = gitHubReportFromJson(entry.value(QStringLiteral("report")).toObject());
    if (!fetchedAt.isValid() || !report) {
        return std::nullopt;
    }
    return Snapshot<GitHubReport>{
        .value = *report, .fetchedAt = fetchedAt, .origin = entry.value(QStringLiteral("origin")).toString()};
}

bool save(const AppPaths &paths, const Snapshot<GitHubReport> &snapshot) {
    QJsonObject root = state(paths);
    root.insert(QStringLiteral("github"),
                QJsonObject{{QStringLiteral("fetchedAt"), snapshot.fetchedAt.toUTC().toString(Qt::ISODateWithMs)},
                            {QStringLiteral("origin"), snapshot.origin},
                            {QStringLiteral("report"), toJson(snapshot.value)}});
    return jsonstore::write(file(paths), limitscache::schemaVersion, root).has_value();
}

} // namespace githubcache

GitHubJob::GitHubJob(GitHubAccount &account, AppPaths paths, int intervalMs, QObject *parent)
    : QObject(parent), m_account(account), m_paths(std::move(paths)), m_interval(intervalMs) {
    m_timer.setInterval(intervalMs);
    connect(&m_timer, &QTimer::timeout, this, &GitHubJob::refresh);
}

void GitHubJob::start() {
    m_state = SourceState<GitHubReport>::loading(githubcache::load(m_paths));
    Q_EMIT stateChanged();
    refresh();
    m_timer.start();
}

void GitHubJob::refresh() {
    if (m_fetching || m_paused || (m_waitUntil.isValid() && QDateTime::currentDateTimeUtc() < m_waitUntil)) {
        return;
    }
    m_fetching = true;
    m_account.report(QDateTime::currentDateTime(), QLocale().firstDayOfWeek(), this,
                     [this](std::expected<GitHubReport, SourceError> outcome) { finish(std::move(outcome)); });
}

void GitHubJob::tokenChanged() {
    m_paused = false;
    m_waitUntil = {};
    refresh();
}

void GitHubJob::finish(std::expected<GitHubReport, SourceError> outcome) {
    m_fetching = false;
    if (outcome) {
        const Snapshot<GitHubReport> snapshot{
            .value = std::move(*outcome), .fetchedAt = QDateTime::currentDateTimeUtc(), .origin = origins::github()};
        githubcache::save(m_paths, snapshot);
        m_state = SourceState<GitHubReport>::loaded(snapshot);
    } else if (outcome.error().kind == SourceError::Kind::TokenMissing) {
        m_state = SourceState<GitHubReport>::notConfigured(NotConfiguredReason::GithubTokenMissing);
    } else {
        if (outcome.error().kind == SourceError::Kind::Unauthorized) {
            m_paused = true; // ADR-022
        } else if (outcome.error().kind == SourceError::Kind::RateLimited) {
            m_waitUntil = outcome.error().until; // ADR-020
        }
        m_state = SourceState<GitHubReport>::failed(outcome.error(), m_state.snapshot());
    }
    Q_EMIT stateChanged();
}

} // namespace contribusage::github
```

```cpp
QVariantMap githubView(const SourceState<GitHubReport> &state, const QDateTime &now) {
    using Phase = SourceState<GitHubReport>::Phase;
    QVariantMap view{{QStringLiteral("login"), QString()},
                     {QStringLiteral("statsText"), QString()},
                     {QStringLiteral("updatedText"), QString()},
                     {QStringLiteral("statusText"), QString()},
                     {QStringLiteral("connected"), state.phase != Phase::NotConfigured},
                     {QStringLiteral("stale"), false}};
    if (const auto snapshot = state.snapshot()) {
        const GitHubReport &report = snapshot->value;
        view.insert(QStringLiteral("login"), QString(u'@' + report.calendar.login));
        view.insert(QStringLiteral("statsText"),
                    QString(QStringLiteral("Today ") + QString::number(report.stats.today) + QStringLiteral(" · Streak ") +
                            QString::number(report.stats.currentStreak) + QStringLiteral(" days · Year ") +
                            QLocale().toString(report.calendar.totalContributions)));
        view.insert(QStringLiteral("updatedText"), ageText(snapshot->fetchedAt, now));
        view.insert(QStringLiteral("stale"),
                    snapshot->isStale(now, staleAfterSeconds) || state.phase == Phase::Failed);
    }
    if (state.phase == Phase::Loading && !state.snapshot()) {
        view.insert(QStringLiteral("statusText"), QStringLiteral("Loading…"));
    } else if (state.phase == Phase::Failed) {
        view.insert(QStringLiteral("statusText"), errorMessage(*state.error, QStringLiteral("GitHub")));
    }
    return view;
}

QVariantMap githubHeatmap(const SourceState<GitHubReport> &state, QDate today) {
    const auto snapshot = state.snapshot();
    if (!snapshot) {
        return {};
    }
    QHash<QDate, ContributionDay> byDate;
    for (const ContributionDay &day : snapshot->value.calendar.days()) {
        byDate.insert(day.date, day);
    }
    const auto days = heatmapDays(today);
    QVariantList cells;
    for (const QDate &date : days) {
        QVariantList stripes;
        QString text = QStringLiteral("no data");
        if (const auto it = byDate.constFind(date); it != byDate.cend()) {
            text = QString::number(it->count) + QStringLiteral(" contributions");
            if (it->level > 0) {
                stripes.append(QVariantMap{{QStringLiteral("hue"), QStringLiteral("github")},
                                           {QStringLiteral("level"), it->level}});
            }
        }
        cells.append(QVariantMap{{QStringLiteral("line"), QString(date.toString(Qt::ISODate) +
                                                                  QStringLiteral(" · GitHub: ") + text)},
                                 {QStringLiteral("stripes"), stripes}});
    }
    return {{QStringLiteral("layers"), QVariantList{QVariantMap{{QStringLiteral("name"), QStringLiteral("GitHub")},
                                                                {QStringLiteral("hue"), QStringLiteral("github")}}}},
            {QStringLiteral("columns"), int((days.size() + 6) / 7)},
            {QStringLiteral("cells"), cells}};
}

} // namespace contribusage::github
```

```markdown
# ADR-043: The GitHub token is entered in the popup

- **Decided:** YYYY-MM-DD · **Spec:** FR-16, FR-17, SPEC §11.3 · **Supersedes:** —

## Context
SPEC §11.3 had the not-connected GitHub block open Settings, where the token is entered. The Plasma widget has no Settings pages yet (L-5), and GitHub was wanted before them.

## Options
| Option | For | Against |
|---|---|---|
| Wait for the Settings pages | One place for all settings | GitHub stays hidden until L-5 |
| Token form in the GitHub block | Works now; the place the user looks when GitHub is missing | A password field in a popup |
| Import from `gh auth token` (FR-21) | No typing | Reads another tool's credential store; FR-21 is P3 and button-only |

## Decision
While no token is saved, the GitHub block shows a password field, Connect and a link to create a read-only token. The token is validated with `viewer { login }`, then saved in KWallet; the field is cleared on submit and the token never becomes a QML property.

## Consequences
```
