# L-5b: Popup Layout, GitHub Label Data and Low Power — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** The popup follows a user layout (block order and visibility, provider sections and their order, heatmap membership and style, "Nothing to show"), work follows use (FR-46), the GitHub label modes show today's contributions, and Low Power Mode doubles the intervals.

**Architecture:**
- **Core:** `popoverlayout.h` ports `PopoverLayout` (block IDs are strings: a provider ID, `heatmap`, `github`) with its JSON form and pure editing functions over that JSON for the settings page.
- **GitHub:** `githubMenuBar(state, today, firstDayOfWeek, now)` gives the label's `MenuBarGitHub`.
- **Platform:** `SystemConditions` reads power-profiles-daemon's `ActiveProfile` (`power-saver` = low power).
- **Applet:** `PopupModel` gains `blocks`, `nothingToShow` and per-provider `sections`; the heatmap keeps only layers in it and draws Combined or Stacked; the activity watcher and GitHub follow the demand; a Popover settings page edits the layout through `PopupModel`'s layout helpers (buttons for up and down instead of drag and drop).

**Tech Stack:** C++23, Qt 6 Core/DBus/JSON, QML, Qt Test.

**Spec:** SPEC §10.8, FR-44 to FR-49, FR-12, FR-20, §12 rule 3, §11.6 Popover tab; ADR-034; Swift `git show 2603a21:Packages/ContribusageKit/Sources/ContribusageCore/Models/PopoverLayout.swift` and its tests.

## Global Constraints

- C++23, `-Werror`, clang-format clean (only `*.cpp`/`*.h`), `QStringLiteral`, `QString(...)` around `QStringBuilder` before `QVariant`; core links only Qt6::Core.
- Block keys: a provider ID, `heatmap`, `github`; the two are reserved (FR-45). Unknown saved keys are kept and ignored. A broken saved layout is the default layout.
- Defaults show everything: providers in registry order, heatmap, GitHub; sections limits, activity, insights; heatmap Combined.

```cpp
#include <QJsonObject>

#include <QMap>
#include <QSet>
#include <QString>

namespace contribusage {

// FR-45: the reserved block keys besides the provider IDs.
inline QString heatmapBlockId() {
    return QStringLiteral("heatmap");
}
inline QString githubBlockId() {
    return QStringLiteral("github");
}

// A provider group's sections in their default order (FR-44).
enum class SectionKind { Limits, Activity, Insights };
QString sectionName(SectionKind kind);
std::optional<SectionKind> sectionFromName(const QString &name);

// What must run besides the limits of every provider that is on (FR-46).
struct Demand {
    QSet<QString> activity;
    bool github = false;
};

// SPEC §10.8, FR-44 to FR-49: the popup's arrangement. The default shows everything.
struct PopoverLayout {
    QStringList order; // saved order; may name unregistered providers, kept and ignored (FR-45)
    QSet<QString> hiddenBlocks;
    QMap<QString, QSet<SectionKind>> hiddenSections;
    QMap<QString, QList<SectionKind>> sectionOrder; // missing sections follow in default order (ADR-034)
    QSet<QString> outOfHeatmap;                     // provider IDs or "github"
    QString heatmapStyle = QStringLiteral("combined"); // or "stacked" (FR-49)

    bool shows(SectionKind section, const QString &provider) const;
    // Showing every section again drops the provider's entry.
    void setShows(SectionKind section, const QString &provider, bool shown);
    // Visible blocks in order, given the registry order and the sources that are on (FR-44, FR-47).
    QStringList blocks(const QStringList &registered, const QSet<QString> &on) const;
    // Every registered block in order, hidden or off ones too: providers, heatmap, GitHub after the saved ones.
    QStringList arranged(const QStringList &registered) const;
    // Puts `block` in `target`'s place among the registered blocks; unregistered saved keys follow them.
    void move(const QString &block, const QString &target, const QStringList &registered);
    QList<SectionKind> sections(const QString &provider) const;
    QList<SectionKind> shownSections(const QString &provider) const;
    void moveSection(SectionKind section, SectionKind target, const QString &provider);
    // The heatmap is on while one of its layers is.
    bool isOn(const QString &block, const QSet<QString> &on) const;
    // The heatmap's layers in block order: sources that are on and in the heatmap, hidden blocks included.
    QStringList heatmapLayers(const QStringList &sources, const QSet<QString> &on) const;
    // FR-46: activity while its section or layer shows or the panel label draws it; GitHub likewise.
    Demand demand(const QSet<QString> &on, const QSet<QString> &menuBar) const;

    bool operator==(const PopoverLayout &) const = default;
};

QJsonObject toJson(const PopoverLayout &layout);

// The `popoverLayout` setting's text; empty or broken text is the default layout.
PopoverLayout popoverLayoutFromText(const QString &text);
```

`src/core/popoverlayout.cpp`:
```cpp
#include "core/popoverlayout.h"

#include <QJsonArray>
#include <QJsonDocument>

namespace contribusage {

namespace {

const QList<SectionKind> defaultSections{SectionKind::Limits, SectionKind::Activity, SectionKind::Insights};

// The elements `saved` names, in its order, then the others in theirs.
template <typename T> QList<T> ordered(const QList<T> &items, const QList<T> &saved) {
    QList<T> result;
    for (const T &item : saved) {
        if (items.contains(item) && !result.contains(item)) {
            result.append(item);
        }
    }
    for (const T &item : items) {
        if (!result.contains(item)) {
            result.append(item);
        }
    }
    return result;
}

template <typename T> void moveTo(QList<T> &items, const T &item, const T &target) {
    const qsizetype from = items.indexOf(item);
    const qsizetype to = items.indexOf(target);
    if (from < 0 || to < 0) {
        return;
    }
    items.move(from, to);
}

QJsonArray stringArray(const QStringList &list) {
    QJsonArray array;
    for (const QString &item : list) {
        array.append(item);
    }
    return array;
}

QStringList strings(const QJsonValue &value) {
    QStringList list;
    for (const QJsonValue &item : value.toArray()) {
        if (item.isString()) {
            list.append(item.toString());
        }
    }
    return list;
}

QStringList sortedList(const QSet<QString> &set) {
    QStringList list(set.cbegin(), set.cend());
    list.sort();
    return list;
}

} // namespace

QString sectionName(SectionKind kind) {
    switch (kind) {
    case SectionKind::Limits:
        return QStringLiteral("limits");
    case SectionKind::Activity:
        return QStringLiteral("activity");
    case SectionKind::Insights:
        return QStringLiteral("insights");
    }
    return {};
}

std::optional<SectionKind> sectionFromName(const QString &name) {
    for (const SectionKind kind : defaultSections) {
        if (sectionName(kind) == name) {
            return kind;
        }
    }
    return std::nullopt;
}

bool PopoverLayout::shows(SectionKind section, const QString &provider) const {
    return !hiddenSections.value(provider).contains(section);
}

void PopoverLayout::setShows(SectionKind section, const QString &provider, bool shown) {
    QSet<SectionKind> hidden = hiddenSections.value(provider);
    if (shown) {
        hidden.remove(section);
    } else {
        hidden.insert(section);
    }
    if (hidden.isEmpty()) {
        hiddenSections.remove(provider);
    } else {
        hiddenSections.insert(provider, hidden);
    }
}

QStringList PopoverLayout::arranged(const QStringList &registered) const {
    return ordered(QStringList(registered) << heatmapBlockId() << githubBlockId(), order);
}

QStringList PopoverLayout::blocks(const QStringList &registered, const QSet<QString> &on) const {
    QStringList shown;
    for (const QString &block : arranged(registered)) {
        if (!hiddenBlocks.contains(block) && isOn(block, on)) {
            shown.append(block);
        }
    }
    return shown;
}

void PopoverLayout::move(const QString &block, const QString &target, const QStringList &registered) {
    QStringList blocks = arranged(registered);
    moveTo(blocks, block, target);
    QStringList rest;
    for (const QString &key : std::as_const(order)) {
        if (!blocks.contains(key)) {
            rest.append(key);
        }
    }
    order = blocks + rest;
}

QList<SectionKind> PopoverLayout::sections(const QString &provider) const {
    return ordered(defaultSections, sectionOrder.value(provider));
}

QList<SectionKind> PopoverLayout::shownSections(const QString &provider) const {
    QList<SectionKind> shown;
    for (const SectionKind kind : sections(provider)) {
        if (shows(kind, provider)) {
            shown.append(kind);
        }
    }
    return shown;
}

void PopoverLayout::moveSection(SectionKind section, SectionKind target, const QString &provider) {
    QList<SectionKind> list = sections(provider);
    moveTo(list, section, target);
    sectionOrder.insert(provider, list);
}

bool PopoverLayout::isOn(const QString &block, const QSet<QString> &on) const {
    if (block == heatmapBlockId()) {
        for (const QString &source : on) {
            if (!outOfHeatmap.contains(source)) {
                return true;
            }
        }
        return false;
    }
    return on.contains(block);
}

QStringList PopoverLayout::heatmapLayers(const QStringList &sources, const QSet<QString> &on) const {
    QStringList layers;
    for (const QString &block : arranged(sources)) {
        if (block != heatmapBlockId() && on.contains(block) && !outOfHeatmap.contains(block)) {
            layers.append(block);
        }
    }
    return layers;
}

Demand PopoverLayout::demand(const QSet<QString> &on, const QSet<QString> &menuBar) const {
    const auto inShownHeatmap = [this](const QString &block) {
        return !hiddenBlocks.contains(heatmapBlockId()) && !outOfHeatmap.contains(block);
    };
    Demand demand;
    for (const QString &source : on) {
        if (source == githubBlockId()) {
            continue;
        }
        if ((!hiddenBlocks.contains(source) && shows(SectionKind::Activity, source)) || inShownHeatmap(source) ||
            menuBar.contains(source)) {
            demand.activity.insert(source);
        }
    }
    demand.github = on.contains(githubBlockId()) &&
                    (!hiddenBlocks.contains(githubBlockId()) || inShownHeatmap(githubBlockId()) ||
                     menuBar.contains(githubBlockId()));
    return demand;
}

QJsonObject toJson(const PopoverLayout &layout) {
    QJsonObject hiddenSections;
    for (auto it = layout.hiddenSections.cbegin(); it != layout.hiddenSections.cend(); ++it) {
        QStringList names;
        for (const SectionKind kind : defaultSections) {
            if (it->contains(kind)) {
                names.append(sectionName(kind));
            }
        }
        hiddenSections.insert(it.key(), stringArray(names));
    }
    QJsonObject sectionOrder;
    for (auto it = layout.sectionOrder.cbegin(); it != layout.sectionOrder.cend(); ++it) {
        QStringList names;
        for (const SectionKind kind : *it) {
            names.append(sectionName(kind));
        }
        sectionOrder.insert(it.key(), stringArray(names));
    }
    return {{QStringLiteral("order"), stringArray(layout.order)},
            {QStringLiteral("hiddenBlocks"), stringArray(sortedList(layout.hiddenBlocks))},
            {QStringLiteral("hiddenSections"), hiddenSections},
            {QStringLiteral("sectionOrder"), sectionOrder},
            {QStringLiteral("outOfHeatmap"), stringArray(sortedList(layout.outOfHeatmap))},
            {QStringLiteral("heatmapStyle"), layout.heatmapStyle}};
}

PopoverLayout popoverLayoutFromJson(const QJsonObject &json) {
    PopoverLayout layout;
    layout.order = strings(json.value(QStringLiteral("order")));
    const QStringList hidden = strings(json.value(QStringLiteral("hiddenBlocks")));
    layout.hiddenBlocks = QSet<QString>(hidden.cbegin(), hidden.cend());
    const QJsonObject hiddenSections = json.value(QStringLiteral("hiddenSections")).toObject();
    for (auto it = hiddenSections.begin(); it != hiddenSections.end(); ++it) {
        QSet<SectionKind> kinds;
        for (const QString &name : strings(it.value())) {
            if (const auto kind = sectionFromName(name)) {
                kinds.insert(*kind);
            }
        }
        if (!kinds.isEmpty()) {
            layout.hiddenSections.insert(it.key(), kinds);
        }
    }
    const QJsonObject sectionOrder = json.value(QStringLiteral("sectionOrder")).toObject();
    for (auto it = sectionOrder.begin(); it != sectionOrder.end(); ++it) {
        QList<SectionKind> kinds;
        for (const QString &name : strings(it.value())) {
            if (const auto kind = sectionFromName(name)) {
                kinds.append(*kind);
            }
        }
        layout.sectionOrder.insert(it.key(), kinds);
    }
    const QStringList out = strings(json.value(QStringLiteral("outOfHeatmap")));
    layout.outOfHeatmap = QSet<QString>(out.cbegin(), out.cend());
    if (json.value(QStringLiteral("heatmapStyle")).toString() == QStringLiteral("stacked")) {
        layout.heatmapStyle = QStringLiteral("stacked");
    }
    return layout;
}

PopoverLayout popoverLayoutFromText(const QString &text) {
    const QJsonDocument document = QJsonDocument::fromJson(text.toUtf8());
    return document.isObject() ? popoverLayoutFromJson(document.object()) : PopoverLayout();
}

QString popoverLayoutText(const PopoverLayout &layout) {
    return QString::fromUtf8(QJsonDocument(toJson(layout)).toJson(QJsonDocument::Compact));
}

} // namespace contribusage
```

```cpp
namespace {
const QStringList registeredProviders{QStringLiteral("claude-code")};

QString blockName(const QString &block) {
    return block == heatmapBlockId() ? QStringLiteral("Heatmap")
         : block == githubBlockId()  ? QStringLiteral("GitHub")
                                     : QStringLiteral("Claude Code");
}
} // namespace

QVariantList PopupModel::layoutRows(const QString &text) const {
    const PopoverLayout layout = popoverLayoutFromText(text);
    QVariantList rows;
    for (const QString &block : layout.arranged(registeredProviders)) {
        QVariantMap row{{QStringLiteral("id"), block},
                        {QStringLiteral("name"), blockName(block)},
                        {QStringLiteral("shown"), !layout.hiddenBlocks.contains(block)}};
        if (block != heatmapBlockId()) {
            row.insert(QStringLiteral("inHeatmap"), !layout.outOfHeatmap.contains(block));
        }
        if (registeredProviders.contains(block)) {
            QVariantList sections;
            for (const SectionKind kind : layout.sections(block)) {
                sections.append(QVariantMap{{QStringLiteral("name"), sectionName(kind)},
                                            {QStringLiteral("shown"), layout.shows(kind, block)}});
            }
            row.insert(QStringLiteral("sections"), sections);
        }
        rows.append(row);
    }
    return rows;
}

QString PopupModel::layoutMoveBlock(const QString &text, int from, int to) const {
    PopoverLayout layout = popoverLayoutFromText(text);
    const QStringList blocks = layout.arranged(registeredProviders);
    if (from < 0 || to < 0 || from >= blocks.size() || to >= blocks.size()) {
        return text;
    }
    layout.move(blocks.at(from), blocks.at(to), registeredProviders);
    return popoverLayoutText(layout);
}

QString PopupModel::layoutSetShown(const QString &text, const QString &block, bool shown) const {
    PopoverLayout layout = popoverLayoutFromText(text);
    if (shown) {
        layout.hiddenBlocks.remove(block);
    } else {
        layout.hiddenBlocks.insert(block);
    }
    return popoverLayoutText(layout);
}

QString PopupModel::layoutSetInHeatmap(const QString &text, const QString &block, bool in) const {
    PopoverLayout layout = popoverLayoutFromText(text);
    if (in) {
        layout.outOfHeatmap.remove(block);
    } else {
        layout.outOfHeatmap.insert(block);
    }
    return popoverLayoutText(layout);
}

QString PopupModel::layoutSetSectionShown(const QString &text, const QString &provider, const QString &section,
                                          bool shown) const {
    PopoverLayout layout = popoverLayoutFromText(text);
    if (const auto kind = sectionFromName(section)) {
        layout.setShows(*kind, provider, shown);
    }
    return popoverLayoutText(layout);
}

QString PopupModel::layoutMoveSection(const QString &text, const QString &provider, int from, int to) const {
    PopoverLayout layout = popoverLayoutFromText(text);
    const QList<SectionKind> sections = layout.sections(provider);
    if (from < 0 || to < 0 || from >= sections.size() || to >= sections.size()) {
        return text;
    }
    layout.moveSection(sections.at(from), sections.at(to), provider);
    return popoverLayoutText(layout);
}

    PopoverLayout layout = popoverLayoutFromText(text);
```
