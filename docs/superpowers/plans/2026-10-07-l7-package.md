# L-7: Arch Package and Resource Budget — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** An Arch package of the widget that builds with `makepkg` from this checkout (tests run in `check()`), the minute tick confined to an open popup, and the port design's resource budget measured on the target machine and recorded.

**Architecture:**
- **Applet:** the minute tick (ages, countdowns) runs only while the popup is open (port design §4: "the minute tick runs only while the popup is open or the label shows a countdown"; no label style shows a countdown).
- **Packaging:** `packaging/arch/PKGBUILD` (package `plasma6-applets-contribusage`) builds the checkout it sits in; a CMake test checks the installed file list.
- **Measurement:** a research page with the method and the numbers for the three budget checks, taken with the Release build from the package.
- **Rulings taken in the plan:** the PKGBUILD builds its own checkout (no `source` download; an AUR variant with a git URL waits for the branch to be pushed); `pkgver` is static and bumped by hand (a `pkgver()` function would rewrite the committed file); no clean-chroot build (`devtools` is not installed); the package is built, never installed, in this milestone.

**Tech Stack:** CMake, makepkg, namcap, ps, Qt Test.

**Spec:** port design `docs/superpowers/specs/2026-10-04-linux-plasmoid-port-design.md` §4 (resource budget), SPEC §17.8 L-7, NFR-1, NFR-2, NFR-7.

## Global Constraints

- Nothing is installed on the system and the real panel is not touched; the package is built and inspected only.
- The package installs exactly the applet plugin and the license.
- The build keeps `-Werror` under makepkg's optimization flags.

## Review Focus

1. **makepkg's flags (`-O2`, `_FORTIFY_SOURCE`, LTO) with `-Werror`.** Expected: the package builds; a new warning is fixed in the code. Pinned in Task 2 (the makepkg run).
2. **Tests inside `check()`** (no display, no session bus). Expected: they pass offscreen. Pinned in Task 2.
3. **The popup closed for a long time.** Expected: no minute timer. Pinned in Task 1 (`theMinuteTickRunsOnlyWhileOpen`).
4. **An extra file creeping into the package** (a static library, a test). Expected: the install check fails. Pinned in Task 2 (`install_layout`).
5. **The budget numbers** depend on the machine and on Claude Code writing transcripts at the time. Expected: the page states the conditions. Pinned in Task 3.

- [ ] **Step 3: Write the PKGBUILD**

`packaging/arch/PKGBUILD`:
```bash
# Maintainer: contribusage contributors
# Builds the checkout this file sits in (L-7). An AUR variant takes a git URL as its source once the branch is published.
pkgname=plasma6-applets-contribusage
pkgver=0.1.0
pkgrel=1
pkgdesc="Plasma widget: limits and activity of AI coding tools (Claude Code) and your GitHub contributions"
arch=(x86_64)
url="https://github.com/alexdoescodes/contribusage-arch"
license=(MIT)
depends=(gcc-libs glibc kcmutils kconfig kcoreaddons kirigami kwallet libplasma qt6-base qt6-declarative)
makedepends=(cmake extra-cmake-modules git ninja)
optdepends=('claude-code: limits and activity of Claude Code')
source=()
sha256sums=()

_root() {
    realpath "$startdir/../.."
}

build() {
    cmake -B build -S "$(_root)" -G Ninja \
        -DCMAKE_INSTALL_PREFIX=/usr \
        -DCMAKE_BUILD_TYPE=None \
        -DBUILD_TESTING=ON
    cmake --build build
}

check() {
    QT_QPA_PLATFORM=offscreen ctest --test-dir build --output-on-failure -E install_layout
}

package() {
    DESTDIR="$pkgdir" cmake --install build
    install -Dm644 "$(_root)/LICENSE" "$pkgdir/usr/share/licenses/$pkgname/LICENSE"
}
```
(`claude-code` is the name the optional dependency would have; if no package of that name exists, write the optdepend as a plain note `'claude: Claude Code CLI, installed by its own installer'` — check with `pacman -Si claude-code` and `pacman -Ss '^claude'`.)

Generate `.SRCINFO`: `cd packaging/arch && makepkg --printsrcinfo > .SRCINFO`.

`.gitignore` — add `packaging/arch/src/`, `packaging/arch/pkg/`, `packaging/arch/*.pkg.tar.*`, `packaging/arch/*.log`.

### Task 3: The resource budget, measured

**Files:** Create `llm-wiki/research/l-7-resource-budget.md`; modify `llm-wiki/index.md`.

Note whether Claude Code was writing transcripts during the window (this session does), since the activity scan then runs on each debounced change.

The `claude` probe's own CPU is excluded, as the budget says.
