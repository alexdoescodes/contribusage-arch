# L-4: Widget States, Label Styles and Heatmap Keyboard Navigation — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** The widget shows every section state of SPEC §11.3 on real data (skeletons, Retry, Locate…, Show raw output, no local data, a dimmed stale layer), draws the panel label in all seven FR-51 styles with its tints, and lets the heatmap be walked with the keyboard.

**Architecture:**
- **Views (C++):** `limitsView`, `activityView`, `githubView` gain `skeleton` and `action` keys (and `rawOutput`); `HeatmapLayer` gains `dimmed`, carried to each stripe; `labelView` gains `title`, `companion`, `stale`, `source`.
- **QML:** `ProviderGroup`, `ActivitySection`, `GitHubSection` and `HeatmapBlock` render the states; a new `LabelContent.qml` draws a label in one of the seven styles from plain properties (testable without Plasma); `CompactLabel` feeds it from the plasmoid configuration (`config/main.xml`: `menuBarStyle`, `menuBarTint`, `menuBarColor`), which the Settings pages of L-5 edit.
- **Rulings taken in the plan:** the style and tint are configuration keys now, without a settings page (L-5 adds it); in the GitHub label modes (L-5) the GitHub hue applies — until then the label source is Claude Code.

**Tech Stack:** C++23, Qt 6, QML (QtQuick.Shapes), Plasma 6, Qt Test.

**Spec:** SPEC §11.1, §11.3, §11.4, FR-48, FR-49, FR-51, NFR accessibility (§11.7); port design `docs/superpowers/specs/2026-10-04-linux-plasmoid-port-design.md` §3 (look). Swift reference: `git show 2603a21:App/MenuBar/MenuBarArt.swift` (the styles' geometry).

## Global Constraints

- C++23, `-Werror`, clang-format clean (only `*.cpp`/`*.h`), `QStringLiteral`, `QString(...)` around `QStringBuilder` results before `QVariant`.
- Every interactive QML item has an accessible name (SPEC §17.7).
- Colors only through `Theme` (port design §3); red never as a layer hue; from 90 % the meter is red in every tint but monochrome, the heatmap styles keep their hues (FR-51).
- Nothing blocks the GUI thread; QML gets plain maps from the views.

## Review Focus

1. **First start with no cache.** Expected: skeleton bars and rows, never an empty or broken popup. Pinned in Task 1 (`firstLoadIsASkeleton`) and Task 2 (`skeletonShowsWhileLoading`).
2. **A failure after data was shown.** Expected: previous values dimmed, one error line, a Retry button that refreshes. Pinned in Task 1 (`failureOffersRetry`) and Task 2 (`retryButtonShows`).
3. **Unparseable output.** Expected: "Show raw output" reveals the text. Pinned in Task 1 (`unparseableOffersRawOutput`).
4. **A style set to an unknown value in the config.** Expected: the prompt style. Pinned in Task 3 (`unknownStyleFallsBackToPrompt`).
5. **Keyboard at the heatmap's edges.** Expected: the focus stays inside the grid. Pinned in Task 4 (`arrowKeysWalkTheGrid`).

import QtQuick
import org.kde.kirigami as Kirigami

// FR-51 `heatmap` and `sharedHeatmap`: the last three weeks, rows are weeks from Sunday. `onlyHue` keeps the label
// source's stripes (heatmap); empty keeps every layer's (sharedHeatmap).
Grid {
    id: mini

    property var cells: []
    property string onlyHue: ""
    readonly property real side: Math.floor((Kirigami.Units.iconSizes.small - 2 * spacing) / 3)
    // The last three week rows of heatmapDays(): its cells start on a Sunday, one column per week.
    readonly property var recent: {
        const n = cells.length;
        if (n === 0) {
            return [];
        }
        const start = Math.max(0, n - ((n - 1) % 7) - 1 - 14);
        return cells.slice(start);
    }

    rows: 3
    columns: 7
    spacing: 1

    Repeater {
        model: 21
        Rectangle {
            required property int index
            readonly property var cell: index < mini.recent.length ? mini.recent[index] : null
            readonly property var stripes: cell ? cell.stripes.filter(s => mini.onlyHue.length === 0 || s.hue === mini.onlyHue) : []
            objectName: "miniCell"
            width: mini.side
            height: mini.side
            radius: 1
            clip: true
            color: stripes.length === 0 ? Qt.alpha(Kirigami.Theme.textColor, cell ? Theme.emptyCellOpacity : 0) : "transparent"
            Row {
                anchors.fill: parent
                Repeater {
                    model: parent.parent.stripes
                    Rectangle {
                        required property var modelData
                        width: mini.side / Math.max(1, parent.parent.stripes.length)
                        height: mini.side
                        color: Theme.hue(modelData.hue)
                        opacity: Theme.levelOpacity(modelData.level)
                    }
                }
            }
        }
    }
